ANXIETY INDUCER

Copy this entire folder anywhere and open index.html in a modern browser. No server or internet connection needed.

The former Fear visual 04 is now the first/default visual. The five thumbnails contain only Fear studies. The compact bottom controls pause motion and toggle fullscreen. Audio starts on the first interaction, or with Enable sound. The corner speaker button mutes/unmutes continuous Fear audio; the slider adjusts volume. The arrow expands all nine sound-shaping sliders and collapses them again. Browsers require one click to enable audio and may suspend it when backgrounded or the screen locks.

All controls have accessible names. Reduced-motion preferences start the visuals paused. Saved previews are used when WebGL is unavailable.

To edit, change source/main.js or source/template.html. With Node.js installed, run npm install and npm run build inside this folder. Keep previews beside index.html.
